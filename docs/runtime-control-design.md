# 可替换采集框架的运行控制设计

用户目标：先补齐会话复用、风险停机和跨进程暂停，延续实体/上下文/任务独立的设计；后续采集框架尚未确定。本文限定本轮实现和验证边界，不承诺不触发平台限制。

## 模块与依赖

- `core/control/contracts.py`：会话状态、控制能力、请求策略与停止异常，不依赖采集框架。
- `core/control/store.py`：按配置的会话范围持久化暂停、请求尝试与滚动时间窗，使用现有原子写入/文件锁；损坏状态拒绝执行，人工确认不清除请求预算。
- `core/control/runtime.py`：每任务控制上下文；会话租约阻止同范围并发任务，请求发出前扣除预算，平台限制永久暂停至人工确认，网络错误不转成登录操作。
- `core/drivers/base.py`：增加可选控制能力和 `prepare_run(runtime)`，保留 `crawl_keywords(request)`。驱动只依赖控制契约/上下文，不访问内容清洗、卡片或快照内部。
- `core/drivers/mediacrawler_runtime.py`：唯一了解 MediaCrawler/httpx/Playwright 的桥接层。只连接现有浏览器，阻断自动登录，插入 HTTP/导航控制钩子，转发脱敏结构化状态；只清理本任务创建的页面。
- `core/pipeline.py`：注入控制上下文、获取租约、将停止原因和控制报告写入既有清单。控制层不导入 pipeline、normalizer、storage、snapshot 或具体驱动。

后续框架只需声明已实现的钩子并接入同一上下文，或通过等价 IPC 服务调用；清洗、知识库导出、快照格式不变。本轮不新增框架依赖或实现第二套采集器。

## 状态和行为

状态为 UNKNOWN、READY、AUTH_REQUIRED、CHALLENGE、RATE_LIMITED、ACCESS_RESTRICTED、NETWORK_ERROR。只有有效会话允许普通请求；UNKNOWN 只允许会话探测。需要登录、验证码、限流或账号限制时写入持久暂停，停止本任务，不自动重试或切换备用驱动。网络故障中止当前操作，保留 NETWORK_ERROR 语义，不发起登录。

范围由平台和非敏感 `control_scope` 配置定义，同一账号/浏览器使用同一范围，换驱动继续共享。它是操作范围而非账号真实性认证。状态文件仅存范围摘要、枚举、时间、计数和任务 UUID，不保存 Cookie、Token、原始日志、浏览器路径或账号资料。

人工 `--acknowledge-pause` 解除暂停并将状态置为 UNKNOWN，下一次仍须探测，不重置请求记录或代表平台限制已经解除。`--control-status` 仅读取本地状态，两种命令不执行采集。

## 请求与能力

默认真实采集要求运行控制能力；无钩子的驱动拒绝执行。显式 `require_runtime_control=false` 仅作旧插件兼容选择，文档标明不具备本轮保证；模拟和离线任务不受在线暂停影响。

控制对象限制本任务20次、范围每分钟6次、滚动24小时100次受控操作。这些是可配置的工程上限，不是平台安全阈值。API尝试、重试和受控导航在发出前计量；媒体 HTTP 也受控。浏览器自动加载资源/人工操作不在完整计量范围，MediaCrawler 的实际平台请求总数仍为未知；报告分别给出钩子计量及覆盖范围，不伪造零或精确总量。

MediaCrawler 桥使用固定模块入口和 stdin 控制配置，不向公开事件传入凭证。启动时核对所需接口；不兼容或未能确认有效会话时失败关闭。旧纯文本日志仅由适配器解析成风险信号，运行中检测而不是等待退出码；不在核心业务层使用平台专用文本正则。

## 验收与范围

必须覆盖暂停跨实例/进程、同范围换驱动、租约、预算竞争、损坏状态、人工确认保留预算、会话探测门禁、网络错误不登录、零退出风险信号、运行中立即终止、外部浏览器页面保留以及脱敏。

接口替身和本地受控子进程验证桥接行为；不读取真实登录信息，不运行平台采集。真实 MediaCrawler/浏览器版本兼容和账号使用仍需另行在授权环境联调。本轮不合并 PR、不发布 Stable。
