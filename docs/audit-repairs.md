# RC2/RC3 审查修复记录

修复基于 RC2 提交 `1c50929` 的复审意见，并承接维护者 RC3 提交 `e8f586b`。本次修改不提高版本号，也不发布 Stable。

| 审查项 | 本次落实 | 回归覆盖 |
| --- | --- | --- |
| F01 | AST 值域重写、重复/复杂赋值拒绝、跨协程配置锁 | 多次恶意关键词、类型注解、多行值、字符串伪赋值 |
| F02 | 公共 URL/配置/错误脱敏边界；引用白名单持久化及旧明文清理；CSV 转义 | 嵌套凭证、媒体变更、前缀 JSON、未闭合引号、反斜杠回溯、公式空白 |
| F03 | 模拟驱动与缓存显式许可；稳定 ID；真实驱动不宣称支持直查 | 默认拒绝、插件结果门禁、缺失/空/失败状态、来源轨迹 |
| F04 | fact_v2 / render_v2 全量输入；独立制品哈希；真实生成区对账 | 删除/损坏/伪造头、指标与同 ID 洞察变化、重复导出 |
| F05 | 身份校验、固定文件名、明确批注边界、旧文件备份及拒绝歧义 | 短 ID 碰撞、重复标题、CRLF 批注、读取失败、元数据控制标记 |
| F06 | 统一原子写入与跨进程读改写锁 | 写入失败保留原文件、多线程及独立进程并发提交 |
| F07 | 包资源与 CLI 安装入口、快照原子保存、失败退出码、失败清单 | Wheel 安装验收、预算耗尽、取消、熔断回退、显式状态快照 |

其他数据修复包括正文未知完整性、新完整内容替换旧正文、原始发现时间/排名保留、全部变化 JSONL 导入、只导入追加的新记录，以及有效 MediaCrawler 排序/媒体配置。

新卡片 schema 为 `xhs_card_v2`；旧卡升级前保存 `.bak`，无可确认身份的旧标题文件不会按前缀猜测覆盖。既有明文引用迁移不会创建含秘密的备份。遇到卡片边界冲突，应保留原文件并由用户明确修复边界后再执行。

安装包验收脚本为 `tests/package_smoke.py`。真实 MediaCrawler/平台联调、内部 HTTP 请求预算以及人工编辑并发冲突仍需单独验证；完整的稳定发布准入需要这些证据。
